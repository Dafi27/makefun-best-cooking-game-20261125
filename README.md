**Sizzle & Serve** — a complete, original cooking game. Run the lunch rush in a tiny kitchen: orders land on the board with a patience timer, you grab ingredients from the bins, grill the patties, chop the veg, fry the fries, stack each dish on the plate, and serve it at the window before the customer walks out. Six dishes to master, from Crispy Fries to the Deluxe Burger, with patience tips and a combo bonus for chained serves. One 3-minute shift, keyboard and mouse, no network, no downloads — all art and sound are drawn and synthesised in code.

## How to play

- **Orders** appear on the board — each ticket lists the dish and what it needs.
- **Grab ingredients** from the bins (click, or keys 1–6). Patties go on the **grill** (4s, key G), lettuce & tomato on the **chopping board** (2s, key C), fries in the **fryer** (5s, key F).
- **Plate** the finished food (click the plate, or key P), then **serve** at the window (click, or key S) when the plate matches a ticket.
- Serve fast for a patience tip; chain serves for a combo bonus. A ticket that runs out walks away. R restarts, M mutes.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or serve `game/` with any static file server — the game is plain files under `game/` with no build step and makes no network requests.
